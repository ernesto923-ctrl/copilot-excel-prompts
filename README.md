# Copilot 엑셀 데이터 분석 · 프롬프트 라이브러리

"Copilot 엑셀 데이터 분석: 데이터에서 답을 찾는 실무 분석법" 교육 과정의 강의 매뉴얼(PART 4. 프롬프트 라이브러리)을 기반으로 만든, 교육생이 실습 중 바로 복사해서 사용할 수 있는 프롬프트 모음 사이트입니다.

## 기능

- 모듈별(모듈 1~8) 선택 보기 — 각 모듈의 학습 목표, 실습 파일, 유의사항과 함께 프롬프트 제공
- 전체 프롬프트 보기
- 키워드 검색 (예: XLOOKUP, 피벗, 유령문자 등)
- 클릭 한 번으로 프롬프트 클립보드 복사

## 사용 방법

별도 빌드 없이 정적 HTML/CSS/JS 한 파일로 구성되어 있습니다. `index.html`을 브라우저로 열면 바로 동작합니다.
