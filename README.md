# Copilot 엑셀 데이터 분석 · 프롬프트 라이브러리

"Copilot 엑셀 데이터 분석: 데이터에서 답을 찾는 실무 분석법" 교육 과정(에보닉코리아 실무자 대상, 4시간)의 강사용 강의안을 기반으로 만든, 교육생이 실습 중 바로 복사해서 사용할 수 있는 프롬프트 모음 사이트입니다.

## 기능

- 모듈별(모듈 1~4 + 부록) 선택 보기 — 각 모듈의 진행 아젠다, 유의사항과 함께 프롬프트 제공
- STEP①②③ 등 연속된 프롬프트는 한 카드 안에 순서대로 묶어서 표시 (가독성 강화)
- 전체 프롬프트 보기 (총 33개)
- 키워드 검색 (예: XLOOKUP, 피벗, 감성분석, 대시보드 등)
- 클릭 한 번으로 프롬프트 클립보드 복사

## 사용 방법

별도 빌드 없이 정적 HTML/CSS/JS 한 파일로 구성되어 있습니다. `index.html`을 브라우저로 열면 바로 동작합니다.
